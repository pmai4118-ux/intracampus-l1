# U02 wallet implementation plan

Goal: connect an injected EIP-1193 wallet and display verified balance, network and StudentSBT eligibility in Student View, keeping U01 fixtures separate.

Scope/architecture: a small browser wallet controller with subscribable immutable state, generation-based stale response protection and explicit cleanup; React provider/hook for U04/U06; read-only HTTP RPC at a configured public URL, chain checks before reads. SBT reads use the L03 ABI (tierOf and credentials), with integer decoding, pinned block timestamp and no wallet transaction/signature calls. Explicit public environment values provide RPC/SBT until L06's validated manifest is merged. No dependency on the draft L06 branch; do not infer deployment addresses.

Files: frontend/lib/chains.ts (config), wallet.ts (controller/RPC/types), frontend/app/student/WalletPanel.tsx (context/panel), page.tsx and StudentDemo.tsx (separate real/demo modes), styles.css, tests and docs.
